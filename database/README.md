# MySQL / phpMyAdmin

1. Создайте БД `kodformula` (или импортируйте дамп целиком).
2. Импортируйте `schema.sql` через phpMyAdmin.
3. Дамп использует `utf8mb4` и hex-кодирование строк/JSON, поэтому кириллица и кавычки внутри заданий не ломают SQL.
4. В `config/config.php` укажите параметры подключения.

Демо-пароль для аккаунтов: `1234`.

В базе 3 курса, 9 модулей и 30 шагов согласно базовому пакету учебного содержания.

Важно: `schema.sql` содержит отдельные корректные INSERT-запросы; импортируйте его целиком через phpMyAdmin в пустую БД `kodformula`.
